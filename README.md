# DayZ Admin Repair Kit

An admin-focused repair override tool for DayZ.

This mod allows designated users to restore supported items directly to **pristine** condition in a single action, using the appropriate repair kit for the item type.  
Designed primarily for server administration and testing environments.

## Features

- Instantly repairs supported items to pristine
- Works via drag-and-drop (item → kit and kit → item)
- Compatible with vanilla DayZ
- Tested with DayZ Expansion
- Clean, lightweight implementation

## Intended Use

This mod is intended as an administrative tool.  
If server owners choose to provide it to regular players, economy and balance impact is their responsibility.

## Compatibility

- Tested on DayZ 1.28
- Verified working with DayZ Expansion
- Pending 1.29 confirmation

## Localization

Localized kit names and descriptions are included for English, Czech, German, Russian, Polish, Hungarian, Italian, Spanish, French, Traditional Chinese, Japanese, Portuguese, and Simplified Chinese. DayZ falls back to the English text when a client language is unavailable.
